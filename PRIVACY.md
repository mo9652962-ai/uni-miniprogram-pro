# Privacy Policy for uni-miniprogram-pro

**Last Updated:** October 2026

`uni-miniprogram-pro` is committed to protecting developer and user data privacy through strict **local-first** and **zero-telemetry** architecture.

## 1. Zero External Telemetry
- The template contains **no third-party user behavior trackers, no advertising SDKs, and no telemetry beacons**.
- All local quiz history, streaks, and check-in records are stored directly on the user device via `uni.setStorageSync`.

## 2. CloudBase & API Dual-Track Simulation
- The mock and simulation engines operate entirely offline in memory or local storage.
- Real WeChat CloudBase requests execute strictly within the developer's designated WeChat Cloud environment bound to their official AppID.
- No analytics or user telemetry are sent to any external servers operated by the template authors.

## 3. Data Ownership
- Developers and end users retain 100% ownership and custody of all study records, question banks, and user tokens.
- All code runs client-side or on user-controlled infrastructure.
